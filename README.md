# ChatGPT Library publication proof of concept

A minimal experiment: merge a pull request, then publish `library/library-sync-poc.md` into an existing personal ChatGPT Library test file.

Only the named test file is in scope. Real prompts, policies, personal data, credentials, and account-specific Library identifiers are not included.

The event automation is configured in ChatGPT. This repository does not require a VPS or an OpenAI API key. End-to-end publication is experimental until verified.
